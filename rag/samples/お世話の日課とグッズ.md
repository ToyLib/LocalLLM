# お世話の日課とグッズ

> この文書は RAG のデモ用に作った架空の猫の世話メモです。実在の猫・商品・お店とは関係ありません。

## 1 日の流れ

| 時刻 | やること |
| --- | --- |
| 7:00 | 朝ごはん。ミケは薬も (くわしくは「ごはんと薬のメモ」) |
| 7:30 | トイレ掃除 (2 か所)、水の入れ替え (2 か所) |
| 12:00ごろ | ミケは窓辺で日なたぼっこ、ノリは段ボール箱で昼寝。そっとしておく |
| 17:30 | ノリの運動。ねこじゃらしで 15 分遊ぶ。ミケは見ているだけのことが多い |
| 19:00 | 夜ごはん |
| 21:30 | ノリの歯みがき (歯みがきシートで前歯と奥歯をふく) |
| 23:00ごろ | ノリの夜中の運動会。物を落とされないように、棚の上を片づけておく |

## 週ごと・月ごとのお世話

| いつ | やること |
| --- | --- |
| 毎週日曜日の朝 | ノリの体重を量って、冷蔵庫のカレンダーに書く |
| 毎週水曜日と土曜日 | ミケのブラッシング (ラバーブラシで 5 分) |
| 2 週間ごとの土曜日 | 2 匹の爪切り |
| 毎月 1 日 | 自動給水器のフィルター交換 |
| 毎月第 1 土曜日 | トイレの砂を全部入れ替えて、トイレを水洗いする |
| 毎月 15 日 (5 月〜10 月) | ノミ・ダニの薬 |

春 (3 月〜5 月) と秋 (10 月〜11 月) の換毛期は、ノリも毎日ブラッシングします。ノリは抜け毛が多く、放っておくと毛玉を吐きます。

## 爪切りのコツ

- ミケは寝起きでぼんやりしているときに、ひざに乗せて切ると嫌がりません。後ろ足は触られるのが嫌いなので、前足だけで大丈夫です。
- ノリは 1 人では無理なので、2 人で切ります。1 人がバスタオルでくるんで、もう 1 人が切ります。
- 切ったあとは、ごほうびにおやつを 1 本 (その日のおやつの本数に数えます)。
- 深く切りすぎて血が出たら、洗面所の引き出しにある止血パウダーをつけます。

## グッズの置き場所

| もの | 置き場所 |
| --- | --- |
| 爪切り・ブラシ・止血パウダー | 洗面所の引き出しの 2 段目 |
| 歯みがきシート・カリッとデンタル | リビングの棚の右側 |
| フードとおやつの買い置き | パントリーの下の段 |
| トイレの砂の買い置き | 洗面所の棚の上 (紙の砂 7 L × 4 袋が 1 か月分) |
| キャリーバッグ・診察券・保険証 | 玄関の靴箱の上 |
| おもちゃ | リビングのソファの横のかご |

## おもちゃ

- ミケのお気に入りは、羽根のついた釣りざおのおもちゃ「ふわふわバード」。高く跳ねさせると、シニアとは思えない動きでジャンプします。
- ノリのお気に入りは、まぐろの形のけりぐるみ「まぐろくん」。抱えて後ろ足でけり続けます。
- レーザーポインターは、ノリが興奮しすぎて眠れなくなるので使いません。
- ひもやリボンは飲み込むと危ないので、遊んだあとは必ずかごに戻します。

## 爪とぎ

- 段ボールの爪とぎを、リビングと寝室に 1 つずつ置いています。ぼろぼろになったら交換 (だいたい 2 か月に 1 回)。
- ソファで爪をとぎ始めたら、だっこして爪とぎの上に連れて行きます。叱らなくて大丈夫です。
