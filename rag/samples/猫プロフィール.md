# うちの猫たち プロフィール

> この文書は RAG のデモ用に作った架空の猫の世話メモです。実在の猫・人物・病院とは関係ありません。

## ミケ

| 項目 | 内容 |
| --- | --- |
| 種類 | 三毛猫 (メス、避妊手術済み) |
| 誕生日 | 2016 年 5 月 12 日 (シニア猫) |
| 体重 | 4.2 kg (ベストは 4.0〜4.4 kg) |
| 見た目 | 白・茶・黒の三毛。右の前足だけ靴下をはいたように白く、目は緑色 |
| 名前の由来 | 三毛猫だから (くわしくは「うちの子になった日とエピソード」) |
| 性格 | 人懐こく、初めての人にもすぐ寄ってくる |
| 好きなこと | 南向きの窓辺で日なたぼっこ、羽根のおもちゃ |
| 苦手なもの | 掃除機の音、抱っこされたまま立ち上がられること |
| 持病 | 甲状腺機能亢進症 (2025 年 9 月から毎日薬を飲んでいる) |
| 鳴き声 | 高くて小さい声。おなかがすくと台所で「ニャッ」と 1 回だけ鳴く |

ご機嫌のときは、しっぽを立てて「ンーッ」と短く鳴きます。
怒っているときは、しっぽを床にパタパタ打ちつけるので、そっとしておいてください。

### ミケの好きな食べ物

- いちばんの好物は、おやつの「ぺろりスティック (まぐろ味)」。袋を開ける音だけで飛んできます。
- 毎月 12 日 (誕生日の日付) には、ごほうびとして味付けなしのゆでたささみを小さじ 1 杯ぶんあげています。
- かつお味のフードは苦手で、においをかいだだけで立ち去ります。

### ミケの好きな場所

- 午前中は、リビングの南向きの窓辺に置いたキャットタワーのいちばん上。
- 冬 (12 月〜3 月) は、こたつの中にこもっています。
- 夜は、飼い主のベッドの足元で丸くなって寝ます。

## ノリ

| 項目 | 内容 |
| --- | --- |
| 種類 | 黒猫 (オス、去勢済み) |
| うちに来た日 | 2023 年 3 月 18 日 (保護猫、当時推定 1 歳) |
| 体重 | 5.8 kg (**ダイエット中**、目標は 5.2 kg) |
| 見た目 | 全身まっ黒で、胸に小さな白い毛が数本だけある。目は金色。しっぽが長い |
| 誕生日 | 本当の誕生日は不明なので、うちに来た 3 月 18 日をお祝いの日にしている |
| 性格 | 臆病で、来客があるとクローゼットの奥に隠れる |
| 好きなこと | 段ボール箱、夜中の運動会 (23 時ごろ) |
| 苦手なもの | インターホンの音、知らない人の足音 |
| 持病 | なし (2026 年 4 月の健康診断では、体重が多めなこと以外は正常。歯石が少しある) |
| 鳴き声 | 低くて大きい声。夜中の運動会の前に「アオーン」と鳴く |

ノリは早食いで、ミケのごはんまで横取りしようとします。ごはんのときは別の部屋に分けてください。
臆病ですが、慣れた人にはおなかを見せてゴロンと転がります。なでるなら、あごの下と耳の後ろが好きです。しっぽの付け根を触られるのは嫌がります。

### ノリの好きな食べ物

- いちばんの好物は、かつお節。ただしダイエット中なので、今はあげていません (目標の 5.2 kg になったら、ごほうびにひとつまみだけあげる約束です)。
- 味付けなしで焼いた白身魚 (タラなど) も大好きです。
- ドライフードは何でもよく食べますが、ウェットフードはあまり食べません。

### ノリの好きな場所

- 玄関に置いてある大きめの段ボール箱 (ノリ専用なので捨てないでください)。
- 洗面所の洗濯機の上。高いところから廊下を見張っています。
- 来客のときの隠れ家は、寝室のクローゼットの奥。
- 夜中の運動会のあとは、キッチンのマットの上で寝ています。

## かかりつけの動物病院

- **こむぎ動物病院** (担当: さくら先生)
- 診察時間: 9:00〜12:00 / 16:00〜19:00
- 休診日: **水曜日と日曜日の午後**
- 診察券番号: ミケ **M-0512**、ノリ **N-0318**
- 2 匹ともペット保険「にくきゅう保険」に加入していて、窓口で保険証を出せば 7 割まで補償されます。
- 場所は最寄り駅の東口から歩いて 8 分、パン屋「こむぎ堂」の 2 軒となり。駐車場は 3 台ぶんあります。
- 診察や予防接種の記録は「健康と通院の記録」にまとめています。

## 2 匹の関係

- ふだんはつかず離れずですが、冬の日なたでは並んで寝ていることがあります。
- ノリがミケのしっぽを追いかけて、ミケに猫パンチで怒られるのが毎日の恒例です。
- ごはんの取り合いを防ぐため、ミケはキッチン、ノリは洗面所でごはんを食べます。
