# rag/

RAG (検索拡張生成) で参照する文書を置くフォルダです。
この中の `.md` と `.txt` (UTF-8) を再帰的に読み込み、質問に近い部分を回答の参考資料として LLM に渡します。

- `samples/` には、デモ用の架空の文書 (2 匹の猫の世話メモ: プロフィール・ごはんと薬・留守番メモ) が入っています。
- 自分の文書は、このフォルダの直下やサブフォルダに置いてください。`samples/` と `README.md` 以外は `.gitignore` で除外されるので、コミットされません。
- このフォルダはビルドのたびに実行ファイルの隣 (`build/rag/`) へコピーされます。文書を追加・編集したら、もう一度ビルドしてください。
- ビルドせずに別のフォルダを使うときは、環境変数 `LOCALLLM_RAG_DIR` でフォルダを指定します。

詳しくは [doc/rag.md](../doc/rag.md) を参照してください。
