# 箱庭タブ

港町の風景をボタンや日本語の指示で変えるタブです。C++ 版 (ImGui) と Python 版 (Tk) の両方で、チャット・クイズ・迷路に続く 4 番目のタブにあります。

## 操作

「昼の港」は晴れた昼にして灯台を消し、船を港に戻します。「吹雪の夜」は夜に雪を降らせ、灯台をつけて船を走らせます。どちらのボタンもアプリ内で処理でき、LLM への接続は不要です。窓の明るさを個別に変えていた場合も、ボタンを押すと時刻に連動する状態に戻ります。

指示を入力し、Enter または「指示する」で送ると、チャット用の LLM が次の操作のうち 1 つに分類します。

| 指示の例 | 変わるもの | コマンド |
| --- | --- | --- |
| 昼の港に戻して、吹雪の夜にして | 風景全体をプリセットに切り替える | `day` / `blizzard_night` |
| 夕暮れにして | 時刻を夕暮れにする。窓の明るさが時刻に連動していれば一緒に変わる | `dusk` |
| 雪を降らせて、雪だけ止めて、霧を出して | 天気を雪・晴れ・霧に切り替える | `snow` / `clear_weather` / `fog` |
| 灯台をつけて、灯台を消して | 灯台の光を切り替える | `lighthouse_on` / `lighthouse_off` |
| 家の明かりをつけて、家の明かりを消して | 窓を点灯・消灯し、明るさを固定する | `house_lights_on` / `house_lights_off` |
| 船を出して、船を港に戻して | 船を往復させるか、港まで戻して停泊させる | `sail` / `dock` |

たとえば「吹雪の夜」の後で「雪だけ止めて」と送ると、夜のまま晴れに切り替わります。複数の異なる操作や未対応の指示は `unsupported` に分類するよう LLM に指示しており、その結果を受け取ると画面に入力例を出します。通信や JSON の読み取りに失敗した場合はエラーを表示します。

## 実装

- 入力した指示と操作一覧の system プロンプトを、`server.json` の `chat_url` に送ります。LLM の返答は `{"command":"dusk"}` のような JSON で、アプリが操作名を検証して風景に反映します。
- C++ 版は [sandbox_ui.cpp](../src/sandbox/sandbox_ui.cpp) に分類・状態更新・描画をまとめています。ワーカーの結果は `std::future` で受け取り、港町を ImGui の描画リストに描きます。箱庭を表示してアニメーションが動いている間、イベント待ちの上限は 16 ミリ秒です。
- Python 版は [sandbox_ui.py](../python/sandbox/sandbox_ui.py) が操作とワーカーの結果の受け取り、[sandbox_mode.py](../python/sandbox/sandbox_mode.py) が指示の分類と港の状態、[sandbox_scene.py](../python/sandbox/sandbox_scene.py) が Tk の Canvas への描画を担当します。33 ミリ秒ごとに結果を確認し、表示中の Canvas は必要に応じて描き直します。
