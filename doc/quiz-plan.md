# クイズタブの設計メモ

分野を選ぶと 10 問 (4 択) を出題し、最後に点数とねぎらいのメッセージを出すタブを足すための方針です。
ローカルの LLM に問題を作らせ、採点はアプリが機械的に行います。
実装済みです (Python 版、C++ 版とも)。使い方と動きは [quiz.md](quiz.md) を参照してください。

実装では、次の点をこのメモから変えています。

- 問題の JSON は、「正解の番号」ではなく「正解の文 (`correct`) と誤りの文 3 つ (`wrong`)」にしました。4B のモデルで試すと、番号を 1 始まりで答えたり、解説の番号とずれたりして、正解が食い違うことがあったためです。並べ替えと正解の位置の記録はアプリがします。

## 1. 方針

| 区分 | 内容 |
| --- | --- |
| 今回 | 分野を選ぶ → 10 問 → 点数とねぎらい。4 択。1 問ごとに正誤と解説を出す |
| 今回 | 結果画面で、間違えた問題を見直せる |
| 今回 | 分野は設定ファイルで定義する (プログラミング / IT パスポート / 一般常識 / 資料 (rag/) から) |
| 後回し | 正解を伏せて解き直させる検算、ChatGPT での確認、記述式、成績の保存 |
| やらない | カリキュラム、難易度の自動調整 |

- まず Python 版 (Tk) で作り、出来を確かめてから C++ 版に移しました。
- 採点は LLM に頼りません。問題は JSON スキーマで「問題・正解の文・誤りの文 3 つ・解説」を出させ、アプリが選択肢を並べ替えて、正解の位置を覚えておきます。

## 2. 分野 (config/quiz.json)

| キー | 内容 |
| --- | --- |
| `source` | `llm` (モデルの知識から出題) か `rag` (資料から出題) |
| `guide` | `llm` 分野の出題範囲の説明 |
| `topics` | `llm` 分野のトピックの一覧。出題ごとに 1 つずつ割り当て、偏りと重複を防ぐ |

- `rag` 分野は、インデックスのチャンクから重複なしで選び、そのチャンクだけを渡して出題させる。正解が必ず資料に載っているので、一番信頼できる。解説に出典 (資料名と見出し) を出す。
- `llm` 分野は誤った正解が出ることがあるので、画面に注意書きを出す。特に IT パスポートのような用語の細部に注意。
- そのほかの項目: 出題数 `question_count` (既定 10)、`max_tokens`、生成用のプロンプト、点数の帯ごとの固定のメッセージ、ねぎらいに使う回答役 (`agents.json` のキー)。

## 3. 流れ

```
分野を選ぶ → [開始]
  Q1/10 → 回答 → 正誤と解説 → [次へ] → … → Q10/10
  → 結果: 7 / 10 点 + ねぎらい + 間違えた問題の振り返り
        [もう一度] [分野を変える]
```

### 生成は 1 問ずつ、先読みする

10 問を 1 回で作らせると、長くて遅く、小さなモデルでは途中で切れたり形式が崩れたりします。
そこでワーカースレッドが 1 問ずつ順に作り続け、ユーザーが解いている間に次の問題が用意されるようにします。
待つのは最初の 1 問だけで、解くのが速くて追いついたときは「次の問題を準備中…」を出します。

### 重複を避ける

- `llm` 分野: 開始時に `topics` から重複なしで割り当てる (足りなければ循環)。既出の問題文も渡す。
- `rag` 分野: 重複なしで別々のチャンクを選ぶ。資料が少ないときは、出題数をチャンクの数まで減らす。

### 失敗に備える

JSON を検証し (正解と誤りの 3 つがそろい、空でなく重複しない)、だめなら 3 回までやり直します。
それでも作れない問題は飛ばして次に進み、最後まで足りなければ、作れた問題の数で終えます。

### ねぎらいのメッセージ

- 点数の帯 (満点 / 8 割以上 / 5 割以上 / それ以下) ごとの固定文を、結果を出すときにすぐ表示する。
- そのあと、回答役の人格の口調で、点数を踏まえたひと言を LLM に作らせて置き換える。失敗したら固定文のまま。

## 4. 画面

ウィンドウは `ttk.Notebook` で、「チャット」と「クイズ」を切り替えます (チャット画面は作り変えない)。
クイズのタブは次の 3 つの状態を切り替えます。

| 状態 | 内容 |
| --- | --- |
| 分野の選択 | 分野の選択欄、開始ボタン、注意書き |
| 出題中 | 進み具合 (Q3/10) と正解数、問題、4 つの選択肢、回答 / 次へ / やめる、正誤と解説 |
| 結果 | 点数、ねぎらい、間違えた問題の一覧、もう一度 / 分野を変える |

## 5. ファイル

| ファイル | 内容 |
| --- | --- |
| `python/quiz/quiz_mode.py` | 分野の読み込み、出題 (JSON)、採点、先読み、結果のメッセージ (画面を知らない) |
| `python/quiz/quiz_ui.py` | クイズタブ (`QuizTab`) |
| `python/common/rag.py` | チャンクを重複なしで選ぶ関数を追加 |
| `python/chat/chat_ui.py` | チャット画面を `Notebook` の 1 タブにする |
| `config/quiz.json` | 分野、出題数、プロンプト、メッセージ |
| `doc/quiz.md` | 実装後の説明 |

## 6. 発展: 自作の分野 (カスタムプロンプト)

分野を設定ファイルに手で書く代わりに、画面の編集画面で自分のお題を書いて、分野として保存できるようにします。
詳しくは [quiz.md](quiz.md) の「自作の分野」を参照してください。

- 保存先は設定フォルダーの `quiz_custom.json` (名前・プロンプト・`use_rag`)。同梱の `quiz.json` と分け、更新で消えないようにする。
- お題は `guide` として出題プロンプトに差し込むだけ。出題の形式の指示は固定で、書き換えても壊れない。
- 資料を使わないときは、お題からトピックを先に作らせて 1 問ずつ割り当てる (重複と偏りを防ぐ)。資料を使うときは、お題があればお題に近いチャンクを選ぶ。
- 画面は選択画面の「分野を編集…」。一覧・追加・削除・分野名・お題・資料のチェック・テスト出題・保存。
- 今回は入れない: 分野ごとの出題数・難易度・ねぎらいの人格の上書き。
- 追加: 自作の分野に「ChatGPT で出題する」(`use_cloud`) を足した。小さなモデルの誤りを減らすため。「資料を使う」と両方オンにできるのは、設定 (`cloud.allow_rag`、既定はオフ) で許可したときだけで、そのときも資料の一部が外に出るので警告を出す。送る内容は [privacy.md](privacy.md) に書いた。
