# 迷路タブ

日本語でロボットに指示すると、ローカルの LLM が移動命令 (JSON) に訳し、アプリがその命令どおりにロボットを動かすタブです。
障害物を避けて、スタート (左下の S) からゴール (右上の G) まで運びます。少ない指示でゴールするほど高評価です。
ステージが進むと使えない言葉 (禁止ワード) が増え、言い換えの工夫が要ります。C++ 版だけにあります。

## ステージ

| ステージ | 禁止ワード | 工夫のしどころ |
| --- | --- | --- |
| 1 | なし | 少ない指示でまとめる |
| 2 | 数字 (0〜9・０〜９・一〜十)、ひとつ〜いつつ、one〜five | 「ぶつかるまで」「行けるところまで」で距離を伝える |
| 3 | 上下左右・東西南北、うえ・みぎ・ひだり (カタカナも)、英語 (up / north など) | 「まっすぐ」「振り返って」「12時の方向」「天井の方」など |

- 禁止ワードは、LLM に送る前にアプリが文字列で調べます。入っていたら送らず、「『右』は使えません」と出します (回数には数えません)。英字は大文字・小文字を区別しません。
- 文字列で調べるだけなので、「一気に」の「一」も引っかかります。逆に、一覧に無い言い方 (「いち」「みっつめ」など) は通ります。抜け道は見つけた人の勝ちです。
- ひらがなの「した」は、「〜した」とぶつかるので禁止にしていません。
- ステージ 2 の盤は、「進めるところまで進む」だけでゴールできるものに限ります (数字を使えないので)。
- ステージ 3 だけ、LLM にロボットの向き (三角の向き) を教えます。「まっすぐ」「振り返って」が通じるようにするためです。
- どのステージからでも遊べます。ゴールすると「次のステージへ」が出ます。ステージごとの一番良い★を、ステージのボタンに出します (アプリを閉じると消えます)。

## 画面

| 場所 | 内容 |
| --- | --- |
| 上 | 遊び方、指示の回数、最短の道順で曲がる回数 (難しさの目安) |
| 左 | 6×6 のマス目。灰色が障害物。ロボットはスタート (左下の S) から動き、通ったマスに色が付く。三角はロボットの向き |
| 右 | 指示の履歴。指示ごとに、LLM が返した命令・結果・訳すのにかかった時間を出す |
| 下 | 指示の入力欄 (Enter で動かす)、動かす、やり直す (同じ盤で最初から)、新しい迷路 |

ロボットは 1 マスずつアニメーションで進みます。

- 障害物や盤の端にぶつかる移動は、その手前で止めて赤く揺らし、残りの命令は捨てます。次の指示は止まった場所から続けます。
- ゴールのマスに着いたら (通り過ぎる途中でも)、そこで止めてクリアです。盤の上に評価を出します。

## 評価

指示の回数で決めます。命令に訳せなかった指示 (「こんにちは」など) とエラーは数えません。

| 指示の回数 | 評価 |
| --- | --- |
| 1 回 | ★★★ |
| 2 回 | ★★☆ |
| 3 回以上 | ★☆☆ |

## 盤の作り方

スタートとゴール以外のマスから、ランダムに 9〜12 個を障害物にします。
ゴールまで通れて、最短の道順で曲がる回数が 3 回以上の盤だけを使います (まっすぐ行けば着くような簡単な盤を避けるため)。
曲がる回数は (マス, 向き) を頂点にした 0-1 BFS (まっすぐ進むのは 0、曲がるのは 1) で求めます。条件に合う盤は、たいてい数回作り直せば出ます。

## 命令

LLM には次の形だけを出させます (llama-server の JSON スキーマで縛るので、形は崩れません)。

```json
{"moves": [{"dir": "right", "steps": 3, "until_blocked": false}, {"dir": "up", "steps": 1, "until_blocked": true}]}
```

- `dir` は画面から見た向き (`up` / `down` / `left` / `right`)。「右」のような向きの言葉は、断りが無ければ画面から見た向きとして訳させます (ロボットから見た右と取り違えないように)。
- `steps` は 1〜5。数の無い指示は 1、「しばらく」「ちょっと」のようなあいまいな言い方は LLM がマス数を決めます。
- `until_blocked` が true の命令は、`steps` によらず進めるところまで進みます (「ぶつかるまで」「突き当たりまで」「ずっと」など)。障害物や盤の端の手前で止まり、ぶつかった扱いにはしません。
- 1 回の指示で命令は 10 個まで。移動と関係の無い指示は `moves` が空になり、「読み取れませんでした」と出します。

LLM には盤面 (ロボットの位置) を見せません。道順を考えるのはプレイヤーで、LLM は言葉を命令に訳すだけです。
訳す係の system プロンプトは `src/maze_mode.cpp` の `TRANSLATOR_PROMPT` です。
ステージ 3 では `FACING_PROMPT` を足し、時計の文字盤の向き・「空は上」などの常識を教えます (小さいモデルは、教えないとロボットの向きに引きずられやすい)。

## モデルごとの通じやすさ (目安)

ステージ 2・3 向けの言い換えの指示で試した結果です (Qwen は今のプロンプト、ほかは常識を足す前のプロンプト)。

| モデル | ステージ 2 | ステージ 3 | 1 回の時間 |
| --- | --- | --- | --- |
| Qwen3 4B 2507 | 10 / 10 | 17 / 22 | 約 1.3 秒 |
| gpt-5-mini (クラウド) | 9 / 10 | 18 / 18 | 約 2 秒 |
| Gemma 3 4B | 6 / 10 | 3 / 18 | 約 2.4 秒 |

Qwen が外すのは、「時計回りに曲がって」のような向きの回転と、「太陽が昇る方」のような常識の連想です。Gemma は、ほぼ何でもロボットの向きの方へ進めてしまうので、このゲームには向きません。
