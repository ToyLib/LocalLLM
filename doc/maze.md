# 迷路タブ (最初の版)

日本語でロボットに指示すると、ローカルの LLM が移動命令 (JSON) に訳し、アプリがその命令どおりにロボットを動かすタブです。
「言葉 → 命令 → 動き」の流れを確かめるための最初の版で、まだ障害物とゴールはありません。C++ 版だけにあります。

## 画面

| 場所 | 内容 |
| --- | --- |
| 左 | 6×6 のマス目。ロボットはスタート (左下の S) から動き、通ったマスに色が付く。三角はロボットの向き |
| 右 | 指示の履歴。指示ごとに、LLM が返した命令・結果・訳すのにかかった時間を出す |
| 下 | 指示の入力欄 (Enter で動かす)、動かす、リセット |

ロボットは 1 マスずつアニメーションで進みます。盤の外に出る移動は、その手前で止めて赤く揺らし、残りの命令は捨てます。

## 命令

LLM には次の形だけを出させます (llama-server の JSON スキーマで縛るので、形は崩れません)。

```json
{"moves": [{"dir": "right", "steps": 3}, {"dir": "up", "steps": 2}]}
```

- `dir` は画面から見た向き (`up` / `down` / `left` / `right`)。ロボットの向きから見た左右 (「左に曲がる」) はまだ扱いません。
- `steps` は 1〜5。数の無い指示は 1、「しばらく」「ずっと」のようなあいまいな言い方は LLM がマス数を決めます。
- 1 回の指示で命令は 10 個まで。移動と関係の無い指示は `moves` が空になり、「読み取れませんでした」と出します。

LLM には盤面 (ロボットの位置) を見せません。道順を考えるのはプレイヤーで、LLM は言葉を命令に訳すだけです。
訳す係の system プロンプトは `src/maze_mode.cpp` の `TRANSLATOR_PROMPT` です。

## 今後
